# VERDICT — INSUFFICIENT LEVER, not "no interaction"
################################################################################

THE HEADLINE LOOKS POSITIVE AND IS CONFOUNDED. All-pairs gives HIGH-minus-LOW slope
-0.289 with boot95 [-0.639, -0.005], nominally excluding zero. Three controls say do not
believe it:

1. THE POOLED SLOPE FLIPS SIGN between the two samples: +0.059 over all pairs, -0.334 over
   env-matched pairs only. A relationship that reverses when era/park are held fixed is
   reporting the environment, not the opposition.

2. THE BB9 FALSIFICATION CONTROL MOVES AS MUCH AS K9. Pooled dBB9~dOpp slope is +0.067
   against dK9's +0.059 — BB9 should be near-inert to a change in the opposing AVOID-K
   field. Equal response means the all-pairs signal is not K-specific.

3. R-SQUARED IS ~0.002-0.02 across the all-pairs fits. The line explains essentially none
   of the variance.

THE CLEAN TEST IS NULL AND UNDERPOWERED. Env-matched pairs (N=93): HIGH-minus-LOW slope
-0.174, boot95 [-0.721, +0.153] — INCLUDES ZERO. The CI is 0.87 wide against an effect
plausibly of order 0.1-0.3, so this neither detects nor excludes interaction.

THE ROOT CAUSE IS THE LEVER, AND IT IS STRUCTURAL. Across all 14 formats the opposing
Avoid-K field mean spans only 81.36 -> 88.75, a 7.4-point range on the rating scale. Worse,
that range is almost entirely a function of the VALUE WINDOW: every format sharing a window
has an IDENTICAL opposition measure (bronzequick / bronzeheart / latebronze /
bronzecapweekly all 83.80), so those pairs contribute NO contrast at all and are dropped.
The surviving pairs are exactly the ones that also change era, park and pool size. The
opposition lever and the environment lever are the same lever in this corpus.

WHAT THIS MEANS FOR THE ITEM-1 MISS. The pre-registered discriminator was to separate
WRONG-CURVATURE from MISSING-INTERACTION. It cannot do that here. The miss remains
ambiguous, and the ambiguity is now a measured property of the available data rather than
an open analysis step.

WHAT WOULD ACTUALLY SEPARATE THEM (not run, not proposed as a plan):
  - A contrast where opposition moves WITHOUT the value window moving. Within-format
    opponent variation across instances would do it; the per-format aggregates cannot.
  - The eligibility windows are NESTED, so a wider window is a superset. Any cross-window
    contrast therefore changes the pool's composition and its size together.

CAVEATS ON THIS RUN
  - Opposition is computed on the VALUE WINDOW only. bronze-heart (Year 1930-1989),
    diamond-heart (Year 1930-1980) and live-open (Card Type) carry extra eligibility rules
    NOT applied, so their opposition figures are approximations and are flagged in the table.
  - 24 rows across 9 formats were dropped for colliding (Name,VAL,VLvl,Hand) keys.
  - BF floor 600 (IP >= 139.5). Seed 20260721, 2000 bootstrap resamples over PAIRS.
  - Pairs from the same card are not independent; the bootstrap resamples pairs, not cards,
    so its CI is optimistic where one card contributes many pairs (up to 28 for one card).

# INDEPENDENT REPLICATION — same question, different sample construction.
# Strengthens the verdict and corrects one control framing above.

A second run built the pairs differently: it KEPT the pairs where dOpp is exactly zero
(both formats share a value window), giving 807 pairs against the 385 used above.

1. THE SIGN REVERSES WITH THAT CHOICE.
     all 807 pairs      : interaction +0.0143 [-0.0285, +0.0575]  -> includes 0
                          tercile HIGH-LOW +0.1195 [-0.1567, +0.3209] -> includes 0
     385 nonzero-exposure: interaction -0.0722 [-0.1386, -0.0157]  -> excludes 0
                          tercile HIGH-LOW -0.2943 [-0.6480, -0.0123] -> excludes 0
   Same data, same question, opposite sign and opposite significance depending on whether
   422 zero-exposure pairs are included. A result that flips on an analyst choice of that
   kind is not a result.

2. THE BB9 CONTROL IS WORSE THAN I STATED. Above I compared SLOPES (+0.067 vs +0.059) and
   called them comparable. On explained variance the control is far STRONGER than the
   target: pooled R^2 is 0.105 for dBB9 against 0.022 for dK9 on the identical regressor —
   4.7x. The channel that should be near-inert to an opposing AVOID-K field tracks it
   better than the K channel does. That is a decisive argument against reading any of this
   causally, and it is a stronger statement than the one made above.

3. THE EXPOSURE VARIABLE IS DEGENERATE BY CONSTRUCTION. Every config has
   card_value_min = null, so the opposition measure is a deterministic function of
   card_value_max ALONE. Across all 14 formats there are only SIX distinct opposition
   levels, and 422 of 807 pairs (52.3%) have dOpp EXACTLY zero. The windows are perfectly
   nested, so a wider window's opposing field is the narrower one's field plus higher-VAL
   cards: dOpp is monotone in tier and cannot be varied independently of pool composition,
   of which pitchers are eligible, or of era/park.

4. THE ARBITRATING SUBSAMPLE IS TOO SMALL, CONFIRMED. Env-matched AND nonzero exposure:
   N=93, 31 per tercile, HIGH-LOW -0.1666 [-0.7069, +0.1619]. The CI half-width (~0.43)
   exceeds any effect the pooled estimate suggests. Its exposure comes from a handful of
   format pairs, the largest being silverquick->goldslotsdaily (34 pairs).

VERDICT UNCHANGED AND NOW BETTER EVIDENCED: the discriminator cannot separate
wrong-curvature from missing-interaction on this corpus. The obstruction is structural —
opposition is a deterministic function of the value window, and the value window is the
same lever as pool composition and environment.
